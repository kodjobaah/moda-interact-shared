## Public Node use

Import only server-side from `@modainteract/moda-interact-shared/commerce/presentation/node`. The browser presentation barrel never imports this entrypoint. `prepareConversationProductImage(input, dependencies?)` accepts the trusted SOURCE envelope from the pure selector, host-validated public origin/bucket/R2 credentials, and a host child AbortSignal. Hosts skip all configuration/preparation when binding is disabled, no pair is presented, or wrapped caption is too long. Optional deadlineAt is the absolute original turn deadline; budget is min(5000ms, deadlineAt-now-1000ms). Without it the host must already bound the child signal to that remaining-turn budget; Shared still caps to5000ms. Exhausted/pre-aborted work performs no I/O.

The dependencies port injects fetcher, product transformer, synchronous per-attempt transport factory, public probe and clock. A factory-created transport is owned by this call and always closed, including cancellation. The sole product transform is reused; no brand-logo fallback/crop. Public verification uses the same safe fetcher with redirects disabled. Result is READY with validated public metadata, or OMITTED with a closed bounded reason/stage/duration. It never returns credentials, raw bytes, merchant source URL or provider error text and performs no logging/send/admission/configuration lookup. Host logs only bounded semantic fields and keeps final tenant/pair/control/window/admission checks.

One preparation attempt, no retry loop; existing immutable writer and SDK preserve original behavior. A reused object must have identical HEAD type/length/hash/cache metadata. A conflicting object is never overwritten. Key is conversation-products/v1/hash(shopId)/hash(stableJson({productId,variantId}))/hash(encodedBytes).jpg; source URLs never enter keys. Optional preparation failure keeps a valid text answer; it never authorizes a second provider send after admission.

Run `npm run build`, `npm run validate:conversation-product-image-node`, and the Node media tests. The public validator also bundles/executes the browser barrel and forbids Node/sharp/AWS/host-runtime imports. Publication/version/integrity remains SHARED003, with consumers adopting that exact released artifact later.
